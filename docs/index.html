    Get paid in USDC on Solana, by anyone, from any chain

    Make a link, share it. Your customer pays with what they hold on Base, Arbitrum, Ethereum, BNB Chain, Bitcoin, Tron and more. You receive exactly the invoiced USDC in your Solana wallet. If a payment comes up short or a route fails, the customer is refunded automatically.

    For APIs and agents

    The same rail works without a browser. A Sluice-protected API answers 402 Payment Required with its price in USDC on Solana. The buyer creates an order, pays the quoted deposit from any supported chain, and calls again with X-Sluice-Order. The server delivers exactly once, only after it has seen the USDC land in the merchant's Solana account, and returns a receipt signed with its published key.

    $ python3 cli/sluice_buy.py https://api.example.com/api/report/<solana-address> \
    --pay base:USDC --key-file payer.key --max-usd 0.60
402: price 0.40 USDC on Solana -> 9cYF…DReR
order ord_…: send 0.410… USDC on Base to 0x…
deposit ok: https://basescan.org/tx/0x…
  SETTLED: Paid: verified on Solana
receipt signature valid: True; body hash matches: True; Solana settlement re-verified: True

    Add --rail connect to settle through Aurora Intents Connect: the buyer's deposit triggers one Solana transaction that pays the merchant and writes the order id in an on-chain memo, so the payment proves which order it was for.
